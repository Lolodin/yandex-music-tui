# ymusic — лёгкий терминальный клиент Яндекс Музыки

Клиент на Go с интерфейсом в терминале (bubbletea). Звук воспроизводит mpv, которым программа управляет по JSON IPC.
Вместе с mpv занимает до ≈85 МБ RAM: ≈20 МБ сам клиент, ≈30 МБ mpv в простое и до ≈65 МБ, когда заранее подгружен следующий трек.
Официальное приложение на Electron занимает сотни мегабайт.

## Возможности

**Качество**
- **Lossless FLAC** (до 24 бит) через новый API `get-file-info` с подписью запроса. Поток `encraw` расшифровывается (AES-128-CTR) на лету.
  Переключение качества lossless → hq → nq клавишей `c`: текущий трек перезапускается с той же позиции.
- **Путь сигнала** в строке плеера: кодек, разрядность и частота исходника (из FLAC STREAMINFO), битрейт, формат на выходе mpv, аудиовывод.
- **Нормализация громкости** по данным EBU R128 от Яндекса (интегральная громкость в LUFS и true peak). Применяется к каждому треку отдельно,
  компрессии нет, true peak не поднимается выше −1 dBTP. Целевой уровень настраивается, по умолчанию −14 LUFS.
- **Bit-perfect**: эксклюзивный вывод в ALSA, без микшера, ресемплинга, программной громкости и нормализации.
  Индикатор `BIT-PERFECT ✓` появляется только тогда, когда выбрано прямое устройство `alsa/hw:…` и mpv действительно отдаёт на него
  исходную частоту и формат.
- **Gapless**: следующий трек заранее стоит в плейлисте mpv (`--gapless-audio`, `--prefetch-playlist`).
- **Кроссфейд** на двух экземплярах mpv с равномощной кривой. В режиме «умного» кроссфейда используется разметка трека от Яндекса
  (`fade.outStart`/`inStart`): переход начинается там, где трек затухает, а тишина в начале следующего трека пропускается.

**Музыка**
- «Моя волна» и её варианты (Любимое / Незнакомое / Популярное, настроение). Волна по треку, исполнителю или альбому — клавиша `w`.
  Сервер получает события старта, окончания и пропуска трека, лайки и дизлайки, поэтому рекомендации учитывают то, что вы слушаете.
- «Мне нравится», свои и сохранённые плейлисты, альбомы, поиск по трекам, исполнителям, альбомам и плейлистам.
- Очередь, перемешивание, повтор.

**Рабочий стол**
- **Иконка в трее** (StatusNotifierItem, на Ubuntu работает через встроенное расширение AppIndicator). В меню иконки:
  название трека, «Назад», «Пауза» / «Продолжить», «Вперёд», «♥ Нравится», «Выход».
  Иконка показывает состояние: серая — ничего не играет, жёлтая ▶ — играет, жёлтая ❚❚ — пауза.
  Если очередь пуста, кнопка «Играть» запускает «Мою волну».
- **MPRIS**: работают медиаклавиши клавиатуры (⏯ ⏮ ⏭), плеер с обложкой появляется в шторке уведомлений GNOME/KDE,
  ymusic видно из `playerctl`.
- Трей и MPRIS работают, пока открыт терминал с плеером. Окно терминала можно свернуть, а если его закрыть, плеер завершится.
  Без графической сессии (SSH, tty) интеграция просто не включается.

**Офлайн-кэш**
- Прослушанные треки сохраняются на диск уже расшифрованными. При повторном прослушивании сеть не нужна.
- Лимит размера настраивается; первыми удаляются треки, которые давно не слушали. Вкладка «Кэш» и флаг `--offline` работают без сети.
- Перемотку вперёд не нужно ждать, пока докачается файл: дальние диапазоны берутся с CDN напрямую.

## Требования

- Go 1.22+ (для сборки).
- **mpv ≥ 0.37**: нормализация использует опцию `volume-gain`. На более старом mpv клиент работает, но без нормализации и показывает это
  в строке плеера. Для bit-perfect нужен mpv с выводом ALSA. **В snap-версии mpv ALSA нет** (только PulseAudio), поэтому для bit-perfect
  поставьте mpv из репозитория (`sudo apt install mpv`) и укажите в конфиге `mpv_path = "/usr/bin/mpv"`.
  Какие выводы есть у вашего mpv, видно на вкладке «Настройки».
- Подписка Яндекс Плюс. Без неё сервер отдаёт только 30-секундные превью, клиент это показывает и не сохраняет превью в кэш.

## Установка и запуск

Готовый бинарник для Linux x86-64 лежит на странице [Releases](https://github.com/Lolodin/yandex-music-tui/releases):

```sh
tar xzf ymusic-1.0.0-linux-amd64.tar.gz
./ymusic
```

Сборка из исходников:

```sh
git clone https://github.com/Lolodin/yandex-music-tui.git
cd yandex-music-tui
go build -o ymusic ./cmd/ymusic
./ymusic
```

При первом запуске предлагаются два способа входа:
1. Открыть `https://ya.ru/device` (адрес покажет программа) и ввести код.
2. Вставить OAuth-токен. Можно вставить целиком ссылку с `#access_token=…`.

Токен сохраняется в `~/.config/ymusic/config.toml` с правами 0600.

Флаги: `--login` (войти заново), `--token <токен>`, `--offline`, `--config <путь>`. Токен также можно передать в переменной `YM_TOKEN`.

## Клавиши

| Клавиша | Действие |
|---|---|
| `Tab` / `Shift+Tab`, `1`–`8` | вкладки: Волна, Очередь, Мне нравится, Плейлисты, Альбомы, Поиск, Кэш, Настройки |
| `↑↓` / `j k`, `PgUp/PgDn`, `g/G` | навигация |
| `Enter` | играть список с выбранного трека / открыть плейлист, альбом, исполнителя / изменить настройку |
| `Esc` / `Backspace` | назад |
| `/` | поиск |
| `Пробел` | пауза |
| `n` / `p` | следующий / предыдущий |
| `←` `→` / `[` `]` | перемотка ±5 с / ±30 с |
| `+` / `-` | громкость |
| `l` / `L` | лайк играющего / выбранного трека |
| `d` | дизлайк играющего трека (трек пропускается) |
| `w` | волна по выбранному треку, исполнителю или альбому |
| `c` | качество lossless → hq → nq |
| `s` / `r` | перемешивание / повтор (всё, один трек) |
| `R` | обновить список |
| `?` | справка |
| `q` | выход |

На вкладке «Настройки» значения меняются клавишами `←` `→` или `Enter`. Изменения сохраняются в конфиг сразу.

## Конфиг

```toml
token = "..."
quality = "lossless"          # lossless | hq | nq

[audio]
mpv_path = "mpv"              # для bit-perfect: /usr/bin/mpv (не snap)
device = "auto"               # например "alsa/hw:CARD=DAC,DEV=0" (для bit-perfect нужно именно hw:); список — на вкладке «Настройки»
bit_perfect = false
normalize = true
target_lufs = -14.0
transition = "gapless"        # gapless | crossfade
crossfade_sec = 6.0
smart_crossfade = true
volume = 80
mpv_args = []                 # дополнительные аргументы mpv

[cache]
enabled = true
dir = ""                      # по умолчанию ~/.cache/ymusic
max_gb = 5.0

[desktop]                     # применяется при запуске
tray = true                   # иконка в трее
mpris = true                  # медиаклавиши и плеер в шторке GNOME/KDE
```

Режимы взаимоисключающие: в bit-perfect отключаются нормализация, кроссфейд и программная громкость, потому что любая обработка меняет биты.
При bit-perfect через PipeWire или PulseAudio звук может пройти через системный микшер, и тогда клиент честно пишет «не bit-perfect».
То же с устройством `auto`: ALSA `default` на десктопе — это обычно PipeWire, поэтому для bit-perfect выберите на вкладке «Настройки»
устройство вида `alsa/hw:…`. Чтобы получить эксклюзивный доступ к устройству, его не должен держать звуковой сервер.

## Как устроено

```
cmd/ymusic        точка входа, вход в аккаунт
internal/api      клиент API: подпись get-file-info, rotor-сессии (волна), лайки, плейлисты, поиск, вход по коду
internal/stream   локальный HTTP-прокси для mpv: расшифровка AES-CTR с любого смещения, Range, растущий файл, кэш
internal/mpv      запуск mpv и JSON IPC через socketpair (работает и со snap-версией mpv)
internal/player   движок: очередь, gapless, кроссфейд на двух деках, нормализация, bit-perfect, обратная связь волны
internal/desktop  трей (StatusNotifierItem + dbusmenu) и MPRIS через D-Bus, без cgo и GTK
internal/likes    общее для TUI и трея множество лайков
internal/ui       TUI на bubbletea
```

Лог программы и сообщения mpv пишутся в `~/.cache/ymusic/ymusic.log`.

## Ограничения

API Яндекс Музыки неофициальный: протокол взят из открытой библиотеки
[MarshalX/yandex-music-api](https://github.com/MarshalX/yandex-music-api) и может измениться без предупреждения.
